# 算力资金链 Compute Capital Chain

只记变动，不下结论。

一个本地运行的个人看板，只盯一条线：**AI 算力的资金链**——谁出钱、谁下单、谁担保，以及这些钱按什么利率借到。它不是新闻时间线：一件事只有改变了某个数字或某段关系，才会被记成一条"变动"。

> 之前叫"算力账本"。它记的是变动和关系，不是收支流水，所以改了名字；目录和代码里的 `ledger` 只是数据文件夹的名字，没有动。

## 运行

```bash
npm install
npm run dev
```

打开 <http://localhost:5173>。前端在 5173，数据 API 在 8790（只监听本机）。

其他命令：

| 命令 | 作用 |
| --- | --- |
| `npm run check` | 检查数据的引用关系和格式 |
| `npm run typecheck` | 类型检查 |
| `npm run import` | 把导出的日线数据并入 `data/series/` |
| `npm run build` / `npm start` | 打包并以单进程方式运行 |
| `npm run deploy` | 打包成云端只读版并发布到 Cloudflare，见"云端只读版" |

## 三层结构

界面上几乎没有说明文字，信息按三层收起来，每一层只放当下需要的东西：

1. **看板**：卡片、关键数字、一行一条的列表。
2. **点开一行或一张卡**：这一条的历次读数、前后对照、说明和四个字段。
3. **档案**：点任何主体名字，从右边滑出它的完整档案，里面再分节展开。

字号只有四级（12 / 14 / 17 / 28），界面本身是黑白灰，颜色只留给三种钱的流向。图例和算法说明都收在页脚的"读法"里。

## 数字怎么画

数字的变化尽量用图形而不是"A → B"的文字，全部是中性墨色，不用红绿：

- **历次读数的柱子**：一个数字每披露一次就是一根柱子，从零线起画，最深的一根是当前这一条。折叠行上是缩小版，旁边是最新值和这一次的变化；点开是放大版，指到哪一根，下面就换成那一次的原文和信源。几个并列的口径（比如 OpenAI 算力承诺的四种算法）不分深浅，也不算涨跌幅。
- **波动尺**：市场反应画在一把尺子上，中线是 0，灰带是 ±1 倍日常波动，两端是 ±3 倍，圆点在右是向上、在左是向下。
- **区间涨跌条**：档案里当日 / 5 日 / 20 日 / 年初至今 / 距高点共用一条零线，向两边画。今年才上市的公司，"年初至今"换成"上市以来"。
- **走势线**：收益率读数卡和主体摘要卡上的小折线，只看形状。
- **比例条**：四大厂 capex 按比例切成四段；每笔钱前面的短条是它在这一组里的相对大小，颜色跟着钱的种类。

## 四个视图

- **全景**：四列主体（资金成本 / AI Lab / 云与 Neocloud / 硬件）和三种钱的流向（订单、股权、信贷）。AI Lab 只有 OpenAI 和 Anthropic；SpaceX（2026 年 2 月收购 xAI，6 月以 SPCX 上市）和谷歌、微软等放在云一栏。箭头方向就是钱的方向。点一个主体，右栏换成它的摘要卡，只留下和它有关的线；"回路"筛出钱在两家之间双向流动的关系。
- **变动**：按日期倒序，一条一行，行尾的三格信号条是市场反应的强弱。点开后是这个数字的历次读数、前后对照和四个字段：
  - **信源**：谁发的、属于哪一类（一手披露 / 媒体报道 / 匿名消息 / 机构研究……）。只标注，不评价真假。
  - **新增量**：新增、符合预期、还是重复。
  - **反应**：算出来的数字，见下。
  - **验证**：到哪一天、看什么。
- **利率**：政策利率、5/10/30 年期美债、信用端。联储官员每人一张卡，折叠时是最新一次怎么说，点开是上一次的说法、原话和当日收益率。
- **验证**：所有待核对的日子，过期未核对的排最前。

**档案**分五节：走势、变动、数字、资金、待验证，默认只展开走势。

## 上市状态

主体有三种状态，界面上分别处理：

| 状态 | 例子 | 怎么显示 |
| --- | --- | --- |
| 已上市 | SpaceX（SPCX，2026-06-12 上市） | 自己的报价、走势和市场反应 |
| IPO 进行中 | Anthropic（ANT） | 全景图上是虚线框和"ANT · IPO 11/19"；摘要卡和档案里是发行区间和一条进度（招股书 → 路演 → 定价 → 交易），日期是预计的会标"预计"；走势暂时用关联上市公司的 |
| 未上市 | OpenAI | 标"未上市"，按"提到谁就关联谁的股票"显示关联上市公司的走势 |

IPO 中的代码会和其他标的一起轮询：开始交易那一刻报价就出现在全景图上；第一个交易日收盘、有了日线之后，服务端自动把它当作已上市（`npm run check` 会提示可以把数据里的 `ipo` 换成 `ticker` + `listed`）。Anthropic 的 IPO 内容全部来自公开报道和招股书转述。

## 市场反应怎么算

- 股票：事件当天的涨跌（盘后事件取下一个交易日），扣掉 beta × 纳指 100，再除以此前 60 个交易日的残差波动。
- 利率：当日变动的基点数，除以此前 60 个交易日的日波动。
- ≥2 倍记"显著"（三格），1–2 倍"轻微"（两格），不到 1 倍"无明显反应"（一格），还没收盘记"待收盘"（空格）。
- 同一天同一标的有别的记录、或当天纳指 100 自身波动超过 2 倍时，会标 † 并注明这段涨跌不能单独归因。

这是一把尺子，量的是"动了多少"，不回答"为什么"和"接下来"。

## 实时

点右上角"接通实时"，页面会给出一个 moomoo 授权链接，**需要你本人点开并同意**（"断开实时"在页脚）。之后：

- 本机服务每 10 秒取一次全部标的的报价（休市时 60 秒），通过 SSE 推给页面，页面自动刷新。
- 盘中会用实时价临时算当天的市场反应，标"暂计"；收盘后自动换成正式收盘价并写回 `data/series/`。
- 数据里新增了上市标的时，服务连上后会自动把它最近一年的日线拉下来，不用手动导入。
- 每 30 秒轮流查一个主体的资讯标题，放进变动页的"待整理"——只带信源，不做任何判断，等待整理成正式变动。

权限：只申请 `quote:read`（读行情），服务端代码也只允许调用三个只读工具。授权信息存在 `.local/moomoo-auth.json`（权限 600，不进版本库）。"断开"会删除这个文件。

## 云端只读版

给别人看的版本放在 Cloudflare 上，只有静态文件，没有服务端代码：

```bash
npm run deploy
```

这一条会依次检查数据、打包（`npm run build:cloud`，输出到 `dist-cloud/`）、发布。第一次发布前需要你本人登录一次 Cloudflare：`npx wrangler login`。

- 云端版显示的是**打包那一刻的收盘数据**，顶栏只有"11/10 收盘"这样的日期，没有"接通实时"。想更新，就在本机再跑一次 `npm run deploy`；别人开着的页面切回来时会自动取到新数据。
- moomoo 的授权信息只在本机的 `.local/` 里，不打包、不进仓库、不上传。实时行情用的是这份个人授权，所以实时只在本机版里有。
- 页面带 `noindex`，搜索引擎不收录；但没有登录，拿到链接的人都能打开。
- 发布前想先看一眼：`npm run build:cloud && npm run preview:cloud`，打开 <http://localhost:8791>。

## 目录

```
data/ledger/     数据本体：entities / relations / metrics / changes / officials / calendar / sources
data/series/     日线；data/intraday/ 收益率 5 分钟线
server/          Hono API：store（读写）、compute（统计与市场反应）、live（实时通道）
src/             React 前端：views/ 各视图，viz.tsx 数字的图形，charts.tsx 手写 SVG 折线图
shared/types.ts  前后端共用的数据结构
scripts/         dev（本机开发）、check（数据自检）、export-static（云端版的静态数据）、import-klines
public/          随前端一起发布的文件：_headers（不让搜索引擎收录）、robots.txt
wrangler.jsonc   Cloudflare 的发布配置
docs/INGEST.md   记一条变动的规程
```

## 已知的边界

- 内容截至 2026-11-10，由公开报道和披露整理而来；之后的变动需要按 `docs/INGEST.md` 手动或让 Claude 代为录入。
- Anthropic 的定价日（11/18）和交易日（11/19）是招股书报道里的预计日期，moomoo 的待上市列表里日期还是"待披露"，实际日期变了要改 `entities.json` 里的 `ipo.steps`。
- 历次读数的柱子按披露的先后等距排列，不按真实时间间隔；时点写在每根柱子下面。
- 收益率 5 分钟线只有常规交易时段，盘前公布的数据只表现为开盘跳空。
- 实时通道已在盘前时段实测：报价轮询、收益率读数、资讯标题解析、服务重启后页面自动恢复都正常。盘中"暂计"的市场反应和收盘时自动落盘，要等常规交易时段才会触发，还没有实测过；IPO 代码开始交易当天自动接上报价这一段，也要等 ANT 真正开始交易才能验证。
- 展开、抽屉、换页三种动效用的是较新的 CSS 能力，在 Chrome / Edge 上完整；Safari 和 Firefox 上部分动效会退化成直接显示，功能不受影响。
- 美债休市的日子（如退伍军人节）拿到的收益率是上一个交易日的读数，页面会标出那一天的日期而不是"实时"。
- 云端只读版不会自己更新：数据停在最后一次 `npm run deploy` 的那个收盘日。
- 行情来自 moomoo，仅供个人使用；云端版只带收盘数据，不转发实时行情。本项目不构成投资建议。
